# Ziren Browser Bridge

Экспериментальный мост между Chromium-браузером и локальным ядром Ziren.

## Что делает

- собирает только видимые DOM-элементы текущей страницы;
- передаёт их локально на `127.0.0.1:8788`;
- Ziren ищет нужный элемент по тексту и роли без vision-координат;
- расширение само рисует рамку по реальному `getBoundingClientRect()`;
- физические клики через Browser Bridge в этой версии отключены.

Содержимое страницы не отправляется в отдельный облачный сервис Browser Bridge. Для точного локального совпадения запрос обрабатывается в Core. Старый vision-маршрут остаётся fallback, если DOM-цель не найдена.

## Opera GX — установка для теста

1. Обновить ветку Core `agent/screen-element-resolver-2026-08-07`.
2. Открыть `opera://extensions`.
3. Включить режим разработчика.
4. Нажать **Load unpacked / Загрузить распакованное расширение**.
5. Выбрать папку `browser_bridge_extension` из репозитория `ziren-assistant-v2`.
6. Перезагрузить тестовую страницу.
7. Запустить Ziren Core.

В логах Core после запуска должен появиться `Browser Bridge запущен`. После открытия обычной страницы расширение начнёт отправлять локальные снимки DOM.

## Быстрый тест

На странице с текстом `Бюджет` сказать:

`Мелисса, покажи мне, где здесь можно выбрать бюджет.`

Если DOM-совпадение однозначное, vision-AI не используется для координат, а рамка рисуется расширением прямо вокруг реального элемента или группы элементов.

Следующая фраза `Покажи это прям` использует сохранённую последнюю DOM-цель и не ищет её заново.
