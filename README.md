# Ziren Assistant Core

Локальное Python-ядро Ziren: голосовой ввод, синтез речи, маршрутизация
команд, управление приложениями, окнами, звуком и музыкой.

## Авторизация

Core не принимает пароль пользователя и не доверяет локальному
`session.json` как доказательству входа. Desktop-клиент запускает процесс с
переменной `ZIREN_DESKTOP_TOKEN`, после чего Core проверяет токен через
`GET /api/desktop/me` на auth-сервисе.

Запросы чата и AI-выбора приложения отправляются через публичный защищённый
gateway `AUTH_SITE_URL/api/assistant/*`. Прямого доступа к закрытому
`ziren-ai-service` у Core нет.

Для ручного локального запуска можно создать `.env` по `.env.example`, но
реальный токен нельзя сохранять в git или передавать в аргументах командной
строки.
